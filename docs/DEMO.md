# Demonstration checklist

Use this order for a five-minute judging conversation.

1. Open the landing page. Read the headline and point out that a quiet result is not a safety promise.
2. Choose Check a Message. Paste: `Your account is suspended. Send the one-time code immediately.`
3. Show the indicator list, the strength label, and the sentence that says this is not confirmed fraud.
4. Paste `The club meets on Thursday after school in the library.` Show “No major indicators detected” and the limitation.
5. Open Check a Link. Paste `https://accounts.google.com.secure-login.example.net/verify`. Show the lookalike-domain indicator. Say the site was not opened.
6. Paste `http://127.0.0.1/admin` and show that a private address is flagged and not contacted.
7. Open Scholarships. Read the demonstration banner. Filter to Nigeria and to expired.
8. Open one Academy lesson, answer the questions, and show the feedback.
9. If Supabase is configured, sign in, save a report without the excerpt box, then delete it.
10. If a model file has been trained, show the separate model note. If it has not, say the model is unavailable and the rules are the evidence.

Do not quote an accuracy number unless `ml/models/evaluation.json` exists from a run you performed.
