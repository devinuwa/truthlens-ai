# Judge summary

TruthLens AI is a digital-safety companion for students. It explains warning signs in a message or a link, keeps a quiet result from sounding like a guarantee, and shows educational opportunities with an honest verification label.

The checks that run in the demo are transparent rules in the Next.js server. A Python service can score text with TF-IDF and logistic regression after a licensed dataset is added. No accuracy figure is claimed until that evaluation file exists.

Accounts are optional. Reports belong to the signed-in user, the original text is stored only by choice, and pasted links are not fetched.

The built-in scholarships are fictional demonstration records. They exist so a judge can see filters, deadlines, and status labels without being shown a fake live award.
