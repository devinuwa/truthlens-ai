# Security policy

## Supported use

TruthLens AI is a student project. Report a vulnerability privately if it exposes another user's reports, leaks the service-role key, or causes the server to fetch a user-supplied address.

## Please include

- The page or route
- What you expected
- What happened
- Whether you used a guest session or an account

Do not include a real password, identity number, or a full private message in the report.

## Out of scope

- A rule missing a new scam phrase
- A demonstration opportunity that is clearly labelled fictional
- The absence of a trained model

There is no paid bug bounty.
