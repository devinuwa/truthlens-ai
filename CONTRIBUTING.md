# Contributing

TruthLens AI is open source under the MIT licence.

- Open an issue or a pull request on `devinuwa/truthlens-ai`.
- Keep the language understandable for a secondary-school student.
- Do not describe a result as completely safe.
- Do not add a fetcher for user-supplied URLs.
- Do not commit secrets, datasets, or model binaries.
- Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before a pull request.
- If you change the Python service, also run `npm run test:ml` after installing `ml/requirements.txt`.

New opportunity rows need a real source, a last-verified date, and an honest verification status. Fictional examples must stay marked as demonstration data.
